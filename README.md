## What This Is

This is the **proposed new website** for Abundance Logistics Ltd., Kampala Uganda.  
It is a static HTML site — one file, no database, no WordPress dependency.

Built and maintained by the design team. For review and client sign-off before deployment to [abundancelogistics.com](https://abundancelogistics.com).
